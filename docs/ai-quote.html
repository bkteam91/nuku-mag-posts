AI 현장툴 #03

카톡 의뢰로 견적서 틀 뽑는 프롬프트

의뢰 카톡을 붙여넣으면 항목·수량·조건·확인 질문까지 정리돼요. 단가는 비워 두고 내가 채우는 방식이에요. 무료 제미나이로 직접 돌려 봤어요.
한눈에
  • 단가는 AI에 맡기지 마세요. 프롬프트에 '비워 둬'를 꼭 넣어요
  • 항목은 기획 / 촬영 / 편집·후반 / 기타로 나눠 달라고 하면 빠뜨리는 게 줄어요
  • 표 아래 조건 5줄(수정·납품·대금·취소·유효기간)이 나중에 나를 지켜줘요
  • AI가 쓴 조건 속 숫자는 예시예요. 내 기준으로 고치세요

이렇게 나와요

카페 오픈 홍보영상 의뢰 카톡(릴스 30초 1개 + 15초 2개, 촬영 하루)을 넣었더니 1분 안에 아래처럼 나왔어요. 15초 파생 2편, 장비대, 교통비까지 따로 잡아 줬고, 예산 200은 금액에 반영하지 않았어요(단가를 비워 두라고 했으니까요).

프롬프트

[카톡 의뢰] 아래에 받은 의뢰를 그대로 붙여넣고 보내세요.

프롬프트
아래 카톡 의뢰로 영상 제작 견적서 초안을 표로 만들어줘. 표의 열: 구분 | 항목 | 내용 | 수량 | 단위 | 단가 | 금액 규칙: - 단가·금액 칸은 비워 둬. 내가 직접 채울게 - 구분은 기획 / 촬영 / 편집·후반 / 기타 넷으로 - 표 아래에 '견적 조건' 5줄: 수정 횟수, 납품 형식과 원본 파일 제공 여부, 대금 지급 일정, 일정 변경·취소 시, 견적 유효기간 - 마지막에 의뢰 내용에서 빠져서 클라이언트에게 물어봐야 할 질문 3개 [카톡 의뢰] (받은 의뢰 내용을 그대로 붙여넣으세요)

AI가 써 준 조건 (예시)

위 숫자(2회·50%·3일·20%)는 AI가 넣은 예시예요. 업계 표준이 아니니 내 기준과 상황에 맞게 고치고, 계약서에도 같은 내용을 넣으세요.
  • 수정: 무료 수정 최대 2회, 이후 별도 비용
  • 납품: MP4 제공, 촬영 원본·프로젝트 파일은 기본 미제공(별도 협의)
  • 대금: 계약 시 50%, 납품 후 7일 이내 50%
  • 일정 변경·취소: 촬영일 3일 이내 변경·취소 시 견적 금액의 20%
  • 유효기간: 발행일로부터 14일

덤: 클라이언트에게 먼저 물을 질문

이 질문의 답에 따라 촬영 시간·인력·항목이 바뀌어요. 견적 보내기 전에 먼저 물어보세요.

  • 영업시간 중 촬영인가요, 영업 전·후에 가능한가요?
  • 메뉴는 몇 가지이고, 식기·소품은 매장에서 준비하나요?
  • 인터뷰 헤어·메이크업·의상은 직접 준비하시나요?

엑셀 견적서 양식

단가만 넣으면 금액·공급가액·합계가 자동으로 계산돼요. 기본 항목 12줄과 조건 5줄이 들어 있어요. 부가세 줄은 사업자 유형에 맞게 지우거나 고쳐 쓰세요.

엑셀 견적서 양식 받기

한계

  • 의뢰에 없는 항목(음원 라이선스, 출연료, 장소 대여 등)은 빠질 수 있어요
  • 'BGM 믹싱'처럼 써 줘도 음원 사용료는 따로 잡아야 할 수 있어요
  • 같은 의뢰라도 돌릴 때마다 항목 이름이 조금씩 달라요

체크리스트

  • 단가는 내가 채웠나
  • 수정 횟수 적었나
  • 원본 파일 제공 여부 적었나
  • 대금 지급 일정 적었나
  • 취소·변경 조건 적었나
  • 유효기간 적었나
  • 확인 질문 먼저 보냈나
